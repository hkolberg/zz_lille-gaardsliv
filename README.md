Lille Gårdsliv v0.1 – testversjon

INNHOLD
- Touch-joystick for figur og kjøretøy
- Permanent figurnavn lagret lokalt
- 15 minutters spilldag
- Hjem/gård, jorde, skog, veier og småby
- Traktor og bil
- Såing og høsting av korn
- Korn modnes etter to nye dager og blir stående til det høstes
- Tidlig høstebonus: 120 % første modne dag, 110 % neste, deretter 100 %
- Hønsehus med egg
- Marked for salg av egg og korn
- Gårdskatt som kan koses med
- Progresjon/penger lagres lokalt

TEST PÅ PC/MAC
Åpne index.html i en moderne nettleser.

TEST PÅ IPHONE/IPAD
Den mest pålitelige metoden er å servere mappen over lokalnettet.
På en PC med Python installert:
1. Pakk ut mappen.
2. Åpne terminal/PowerShell i mappen.
3. Kjør: python -m http.server 8000
4. Finn PC-ens lokale IP-adresse, f.eks. 192.168.1.50.
5. På iPhone/iPad på samme Wi-Fi, åpne Safari og gå til:
   http://192.168.1.50:8000
6. Safari > Del > Legg til på Hjem-skjermen.

MERK
Dette er en mekanikkprototype, ikke multiplayer-versjonen ennå.
